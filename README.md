# 极简待办清单（Minimal To-Do List）

一个用于课程作业展示的轻量级待办清单网页小工具。整个应用只有一个 `index.html`，不依赖任何框架、构建工具或 CDN，双击即可运行。

## 项目简介

把要做的事写下来，勾掉，删掉——仅此而已。项目刻意保持极小的体积和极简的交互，用来演示「纯原生前端如何做出一个完整可用的小应用」。

## 功能列表

- **添加任务**：输入内容后按回车或点击「添加」按钮
- **勾选完成**：点击复选框标记完成 / 取消完成，完成项自动加删除线
- **删除单条**：点击任务右侧的 `×` 移除该条任务
- **一键清除已完成**：底部按钮批量清理已勾选的任务
- **实时统计**：底部显示任务总数与已完成数量
- **数据持久化**：基于 `localStorage`，刷新或关闭页面后数据不丢失
- **响应式布局**：桌面端为居中卡片，手机端自动铺满全屏
- **空状态提示**：没有任务时给出引导文案
- **多标签页同步**：同一浏览器多个标签页之间的数据自动保持一致

## 技术栈

| 分类 | 选型 |
| --- | --- |
| 结构 | HTML5（语义化标签） |
| 样式 | 原生 CSS3（CSS 变量、Flexbox、媒体查询、动画） |
| 逻辑 | 原生 JavaScript（ES6：`const/let`、箭头函数、模板字符串、事件委托） |
| 存储 | 浏览器 `localStorage` |

**零依赖**：没有 React / Vue，没有 Tailwind / Bootstrap，没有构建步骤，没有 `package.json`，也没有网络请求。所有代码内联在单个 HTML 文件中，断网也能正常运行。

## 如何运行

方式一（推荐）：

1. 下载或克隆本仓库
2. 直接双击 `index.html`，用任意现代浏览器打开即可

方式二（本地服务器，可选）：

```bash
# 如果希望用 http:// 协议访问，可在项目目录执行
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000/index.html
```

> 提示：直接用 `file://` 打开时 `localStorage` 同样可用，功能不受影响。

## 设计思路

1. **单文件架构**
   把 HTML、CSS、JavaScript 全部内联进一个 `index.html`，用 `<style>` 与 `<script>` 分区块组织。好处是没有构建流程、没有路径依赖、便于提交和演示；代价是文件较长，适合小体量项目，工程化项目仍应拆分模块。

2. **状态驱动渲染**
   全局只维护一个 `state` 对象（`{ todos: [...] }`）作为唯一数据源。所有交互（添加 / 勾选 / 删除 / 清除）都只做同一件事：修改 `state` → 写入 `localStorage` → 调用 `render()` 重绘。UI 永远是状态的投影，逻辑线性、不易出现「界面和数据对不上」的问题。列表使用事件委托绑定，重绘后无需重新绑定事件。

3. **localStorage 存储**
   以 `minimal-todo-v1` 为键，把任务数组序列化为 JSON 存入浏览器本地。读取时做了容错：解析失败、类型不符或单条数据字段异常都会被安全降级，避免一条坏数据导致整个应用白屏；写入失败（隐私模式、空间已满）也不会中断页面运行，只是本次修改不会持久化。

## 浏览器兼容性

支持所有现代浏览器（Chrome / Edge / Firefox / Safari 及移动端浏览器）。使用了 `accent-color`、`env(safe-area-inset-*)`、`Element.closest()` 等特性，IE 不支持。
